# 🤖 GenAI Projects

A collection of beginner-friendly **Generative AI projects** built while learning **LangChain, RAG, LLMs, and AI application development**.

These projects focus on understanding how modern LLM-based applications work through practical implementations using Python and LangChain.

## 🚀 Projects

### 1. 💱 Currency Converter

A simple AI-based currency conversion project demonstrating how an LLM application can work with external tools or data to provide useful responses.

**Folder:** `Currency_Conveter/`

---

### 2. 🎥 YouTube Video Analysing Chatbot

A Generative AI chatbot that analyzes information from YouTube videos and allows users to interact with the video content through natural-language questions.

The project demonstrates concepts such as:

* Retrieval-Augmented Generation (RAG)
* LangChain
* LLM-based question answering
* Document processing
* Context-aware responses

**Folder:** `YouTube_video_analysing_chatbot/`

### 3. 🎥 Ai Agent using LangChain 

simple Ai agents using langchain

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/subhampadhi33537-collab/GenAI_Projects.git
cd GenAI_Projects
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

> If a project has its own dependency requirements, install the packages specified inside that project's notebook.

## 🔐 Environment Variables

Some projects may require API keys.

Create a `.env` file in the project directory and add your required API keys:

```env
GROQ_API_KEY=your_api_key
HUGGINGFACEHUB_API_TOKEN=your_api_key
```

**Never commit `.env` files or API keys to GitHub.**
